## Conversational completion

The intended clinical handoff is a decision list: the question in clinical words, documentary evidence, conditional consequences, chosen/open state and the next useful action. An open historical fact is an evidence task; incomplete encoding is a translation task; a bounded computation is not-computed; a genuine new-trial choice requires declared alternatives with completed feasibility checks under represented constraints. Origin and coverage must be preserved, not reconstructed from a favorable logical label.

Completion claims must name the implemented contract and exercised workflows. Compatible candidates never establish a complete historical protocol, reported frequencies never prescribe a design, and a source correction requires a warranted source rule or independently bound evidence rather than a plausible replacement.
