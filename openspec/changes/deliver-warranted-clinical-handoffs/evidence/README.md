# Clinical handoff verification

This change connects retained source evidence, explicitly attributed premises, existing symbolic
computations, a shared clinical projection, revisions and a separate colleague-facing workbook.
It does not implement automatic clinical prose interpretation or complete protocol writing. A valid
request does not establish the truth of its premises or authenticate a person's confirmation.

## What was exercised

| Claim | Kind and scope | Test and falsifier |
|---|---|---|
| Permissions and necessary conditions survive delivery without stronger eligibility claims | Derivation conditional on represented accepted premises | Direct positive/MUST-NOT tests, solver warrants, CLI/MCP checks; a proposed permission promoted to accepted or an impossible profile given useful conditions falsifies it |
| Revision reports clinical change independently of input change | Computed comparison of two freshly evaluated snapshots | HFrEF widening changes two of seven answers; an independent unchanged answer reported as changed falsifies it |
| Compact delivery retains complete evidence | Artifact preservation, not source-truth certification | Immutable payload digests, exact address/text reconstruction, malformed/collision/symlink controls; changed or missing bytes must refuse |
| Export preserves represented values and origins | File preservation and presentation | Independent cell/link/file read-back, all nine NYHA cells, all 126 HFrEF baseline measurements, literal formula-like text; omitted or reassigned values falsify it |
| Documentation supports a new operator | Bounded observed workflow, not universal usability | Independent cold Phase 1 malaria CLI workflow; its report records both successful distinctions and remaining secondary-sheet noise |

The implementation trace is evidence of actual reachability and consumption, not certification of
clinical meaning. `acceptance/reasoning-consumer-trace.json` contains 90 actual entry-point runs across
50 modules. [The delivery trace](delivery-consumer-trace.json) adds retained-result access, revision
preparation and export through the real CLI entry function. Both include current source hashes.

All 25 active paired examples were replayed through the executable CLI. The
[conservation receipt](example-conservation.json) records unchanged requests and every additive or
explicitly permitted change; existing clinical fields were preserved. All nine emitted machine schemas
validated with Draft 2020-12 and all nine card examples ran through the executable CLI; see
[schema verification](emitted-schema-verification.json). Structural validation remains separate from
cross-field admission, clinical meaning and source truth.

validation, comparator suitability or patient eligibility. Full source bodies, workbooks and canonical

fingerprints are retained here rather than duplicating those large bodies in Git.

## Verification boundaries

The final ordinary local gate passed 6,372 tests with 10 live tests deselected, Ruff checks/formatting
and Ty clean; see [the receipt](final-ordinary-verification.json). The separate live run passed all 10 live checks. Documentation/receipt changes prevented that run from stamping its tree. The exact committed tree is
checked again by the declared pre-push gate; output is retained outside Git.
These are distinct from historical whole-project mutation recertification.

Explicit two-sign receipts are in [proof-receipts](proof-receipts/). Completed packets retain operator
universe, unproven-equivalent and crash-only qualifications. Source/function identity and generated
suite bytes were independently checked before adoption. Incomplete or invalid observations are not
adopted as completed certificates. CrossHair `Not confirmed` is neither a violation nor a proof.

Artifact-size validation stopped at `harvest_cut` (its separate CrossHair contract was confirmed).
MCP argument validation was UNGATEABLE because required verification reached execution bounds.
The canonical record accessor remains incomplete with a 13-line gap after its prescribed replay;
its next inputs are preserved in the receipt. The obsolete alias characterization was preserved
externally and retired rather than hand-edited. Ordinary authored/integration coverage remains active.
The final export-text outcome and deep recertification are recorded in their separate proof receipts.
No whole-project mutation-completeness claim is made.

The cold check's reply-budget discoverability gap was fixed in CLI help and the workflow guide. Detailed
Findings cells still expose exact codes/typed values; the primary Decision list, Options and Markdown
provide the clinical reading surface. This remaining presentation detail changes no computed answer.
