# Proposal

## Why

The HFrEF clinical walkthrough reproduces correct partial computations whose permissions, conditions,
numeric witnesses and revision consequences are poorly exposed. The clinician's main decision list must
be a reproducible program output, and an MCP-only operator must be able to revise and deliver it.

## What Changes

- Repair literal heading format recognition, study-index identity fields and empty annotation noise.
- Expose scoped permission mentions and solver-proved conditional consequences without changing the
  original entailment verdict or promoting a reading, default or declared choice.
- Project a common clinical finding representation for summaries, answer-level revision changes and
  decision exports, retaining complete canonical evidence and existing audit differences.
- Return public result fingerprints, account for bounded solver structure and explain budget refusals.
- Provide bounded public reasoning-artifact access and revision preparation so compact MCP operation
  does not require copying whole results or using internal Python functions.
- Deliver a separate design-review workbook and readable decision list with source addresses, options,
  consequences, standing, origin and open items; retain the verified source workbook independently.
- Provide a compact baseline matrix without joining populations, units or similarly titled groups;
  shorten active discovery and operator context while retaining the complete reference manual.

## Capabilities

### New Capabilities

None: these complete the existing reporting and symbolic reasoning handoffs.

### Modified Capabilities

- `registry-reporting`: literal section formats, bounded identity access, optional annotation clarity and
  faithful compact baseline presentation.
- `symbolic-trial-design`: clinically faithful explanations, public revision/artifact protocol, compact
  discovery/results, structured answer changes and reproducible decision delivery.

## Impact

Shared eligibility/reporting functions; layer-two explanation, session and projection owners; CLI/MCP
delivery shells; workbook/Markdown export; discovery, README, SKILL and project agent guidance. Canonical
results and source records remain retained. No automatic clinical prose compiler, authentication of user
confirmation, clinical recommendation engine or complete protocol writer is introduced.
