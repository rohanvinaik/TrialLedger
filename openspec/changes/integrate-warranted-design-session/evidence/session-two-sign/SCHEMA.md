# Design session schema 1 — frozen administrative contract

This is a scratch implementation contract, not an integrated public operation. Existing reasoning owners compute every clinical consequence. Session orchestration introduces no clinical translation, statistical claim or independent admission policy.

## Request

Exact keys: `operation` = `design_session`, `session`, `previous`. Previous is null or exactly `{session,result,expected_result_digest}`. A previous result is verified by exact canonical JSON SHA256, then both snapshots are freshly replayed. Stored result bytes never replace new execution. The current `parent_digest` must equal the canonical previous session digest. Initial parent is null.

Session exact keys: `{schema_version,id,revision,parent_digest,target,sources,premises,analyses,decisions,limits}`. Version is integer 1. IDs and revisions are nonempty strings. Target is exactly `{kind,ref,scope}`; kind is new_trial or historical, ref is nonempty, and scope is exactly `{study,population,arm,time,version}` with nonempty string values. Every analysis and decision has this complete target object. Alternative feasibility qualifies only under exact target equality. This identifies the declared object of the question; it does not verify its clinical scope.

Sources are `{id,study,expected_digest}`. The actual snapshot owner validates the complete study JSON, NCT identity and canonical content digest. Sources are detached immutable copies. Source_rule assertions are selected by actual IDs from source_assertions.prepare's compiled fixed floor, not supplied status labels.

Premises are exactly `{id,kind,payload,origin,depends_on}`. Kinds: source_assertion, assertion, signal, binding, observation, candidate, corpus_trial, coordinate_evidence, derived_assertion. Origin is exactly `{kind,ref,source,analysis}`; kind is source_rule, source_interpretation, user_choice, hypothesis or derived. Source and analysis are a source/analysis ID or null. Historical single-study projections require target.scope.study to equal the actual source study_ref URI, including digest; corpus descriptors retain their own per-trial identities. Ref is a nonempty attributed reference. Source_interpretation ref is an actual retained source URI with its digest and exact RFC-pointer address; that address must exist. This proves source binding, not the reading. Source_rule is restricted to actual compiled source_assertion. Derived is restricted to derived_assertion. Other payload standing labels remain caller declarations, not source truth. Hypotheses cannot claim known fact standing. A new trial restriction is an explicit user-choice adoption or a same-target derived consequence; a comparator restriction is never silently adopted. Source context may be retained without being an actual support dependency.

`depends_on` lists all claimed support premise IDs. Those premises weaken the dependent premise. Every analysis input is separately retained as a replay/invalidation dependency and does not indiscriminately weaken unrelated local findings. The dependency DAG is bipartite: premise support edges, derived premise -> producing analysis, and analysis -> all used premises. Cycles and unknown references refuse before any solver execution. Returned minimal proof fragments never replace this complete replay graph.

## Analyses and projections

Analysis exact keys: `{id,operation,target,parameters,uses}`. Operations are existing entailment, coordinates, corpus, design_bounds, signals, interpretations or source_assertions. Parameters are existing child-operation fields except operation and owned projected slots. Uses are `{premise,slot,projection}`. Collisions with parameters refuse. Named slots are assertions, signals, bindings, observations, candidates, trials, evidence, fixed_assertions, fixed_signals, study. Fixed slots create the existing fixed object; study is scalar. No arbitrary JSON-pointer replacement or clinical key inference exists.

Projection names:

* identity: typed assertion/signal/binding/observation/candidate to its matching slot, preserving all semantics and provenance. Actual claimed support weakens standing. New-trial assertion adoption is checked explicitly.
* source_study: source ID to actual study plus expected_digest, only for source_assertions.
* coordinate_evidence_identity: payload exactly `{evidence,standing}`, where evidence is the existing NSCLC coordinate shape without standing. Inserts the one attributed standing after support weakening. No semantic mapping or new disease domain.
* corpus_trial: descriptor exactly `{source,stratum,feature_uses,metadata}`. Metadata accepts only sponsor, classes, setting_domain, class_unresolved, eligibility_content, coverage, representation, predicates and start_year. It may not override id, typed, elements, basis, standing or feature_standings. The source's NCT is the ID; a supplied sponsor is an attributed grouping declaration, not verified source identity. If sponsor is omitted, the exact retained leadSponsor.name is used; missing sponsor refuses rather than inventing it. Structural typed is computed from actual represented eligibility elements. All trials remain in the denominator. Each feature retains its own standing, so an independent known age survives another pending reading. Every feature origin source ID must equal the descriptor source ID exactly: another study or another snapshot cannot supply a statement. Clinical metadata defaults to pending and cannot acquire known standing merely from a structural typed flag. Coverage is declared coverage of represented constructs, never full clinical coverage.
* registered_general_age_to_corpus: descriptor feature use `{premise,projection}` selects an actual compiled age source_assertion and emits inclusion:minimum_age=18_Years (maximum analogue), with its actual rule/address/typed object in the projection ledger. No caller feature key or standing override.
* documented_assertion_to_corpus: a required/excluded assertion with source_rule or source_interpretation origin emits inclusion:assertion=<canonical tuple> or exclusion:assertion=<canonical tuple>. Tuple preserves body, modality, cohort and applicability, stripping only Evidence metadata into the separate readable ledger. These are exact representation comparisons, not semantic clinical equivalence or normalization. User choices, hypotheses and derived facts cannot become documented statements.

A derived_assertion payload is exactly `{analysis,query}`. Query is the actual proposition of an ordinary entailment child; exact equality is required. Only an actual ENTAILED/REFUTED result with accepted effective warrant can project that proposition/its negation. Unknown, refusal, out-of-scope, computation gaps and hypothetical frames cannot become facts. The actual deciding result standing is used; all analysis inputs remain invalidation dependencies separately. The produced assertion ID is the premise ID and retains derived origin. Every fixed producer context dimension (cohort, arm, phase) becomes an existing named Scope restriction, conjunctively when needed, so a cohort-A conclusion cannot become a cohort-B fact. This first version deliberately has no arbitrary frame selector.

## Decisions and replay

Decision exact keys: `{id,question,target,coverage,alternatives,selected}`. Coverage is represented_restriction or declared_design and describes caller-declared represented constructs, never all eligibility. Each alternative is `{id,label,analysis,query}` with an exact ordinary entailment query. Selected is null or `{alternative,origin,basis}`, origin exactly user and nonempty basis. A selected option remains visible even if contradicted.

Feasibility requires an actual successful ordinary entailment at exactly the decision target: ENTAILED is feasible; REFUTED infeasible; UNDETERMINED is feasible only with exactly undecided_by_constraints and no unresolved translation, scope, proposed premise or computation limitation. Every child request/result is retained. New-trial choice requires at least two declared feasible alternatives and a completed distinguishing check. There are 2–16 distinct declared exact queries. For each feasible pair under an identical prepared floor/context/bound, the existing entailment owner checks XOR = (Qi and not Qj) or (not Qi and Qj). A completed feasible XOR establishes represented variation; REFUTED establishes equivalence under that floor. Every extra child request/result, warrant, dependency and conservative reservation is retained. Mixed floors and unfinished distinctions remain explicit; they cannot establish design freedom. Known historical questions can be settled within the declared alternatives too. A selected but unchecked option retains chosen_with_open_checks, never a feasibility claim. A historical unknown is an evidence question, never historical design freedom. Refusals are translation questions; resource bounds are computation tasks. Contradictions are blockers. Independently settled results remain alongside local uncertainties.

Output retains schema/version, canonical session digest, immutable source/premise ledgers, complete dependency graph, projection ledger, actual child request/result pairs and digests, question-aware decisions, declared coverage, exact limits/work reservations, and fresh revision diff. Diffs classify stable analysis/decision IDs new, withdrawn, changed or unchanged after both complete fresh executions. Declared work estimates are conservative reservations, not observed solver operation counts. No truncation produces an implied omitted count.

Limits exact keys `{max_analyses,max_premises,max_sources,max_decisions,max_expanded_items,max_solver_work,max_output_bytes}` positive ints under hard ceilings. Nested finite-JSON/depth/node/byte checks run before hydration. Aggregate projected items, analysis reservations and final output bytes are bounded; exceeding a limit refuses the aggregate output rather than dropping evidence. No new dependency or second clinical solver.

Per-alternative feasibility_status is computed from actual accepted deciding support, including considered proof premises for undecided_by_constraints; open states stay null. Decision standing retains a strongest sufficient distinguishing pair, every sole-survivor deciding alternative, or the checked selected option. Deciding origin_refs are separate from complete input_origins. Person selections retain explicit user_choice origin without certifying an open reading.
