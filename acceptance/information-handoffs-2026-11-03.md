# Information preservation and public admission — 2026-11-03

## Object and scope

The old review supplied failure hypotheses, not authority for WHO/ECOG equivalence. The instrument was the
project's distinction between source-defined facts, accepted premises, interpolation and hypothetical
readings. The specimens were current public reasoning requests and the actual reporting consumers.

The initial public reproductions are retained in `reasoning-admission-audit.json`. All their clinical
premises are invented. The date example separately uses the retained IPASS fixture and stored API 2.0.5

## Remaining boundaries

Standing is caller-declared acceptance, not independently verified source truth or human confirmation.
Derived eligibility bounds do not become source-stated corpus criteria. Association abstention currently
works at stratum level; tight bounds over every joint completion of pending features remain future work.
Pending primary statement bounds cover supplied candidate readings, not unrepresented source text.
Low-level Python components retain documented typed-input preconditions. Ordinary entailment's existing
resolution semantics are unchanged; unsupported portions must remain explicitly opaque/unresolved rather
than being silently omitted from an encoded assertion.

The general clinical-text compiler, source/definition registry integration, full default strata, automatic
reasoning orchestration, significance and complete protocol writer remain unfinished OpenSpec tasks. These
repairs improve actual consumers without claiming that those missing components have been built. No full
repository-wide deep recertification or new performance measurement is claimed.
