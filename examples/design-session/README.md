# A managed investigation request

Every premise here is invented. This is a runnable version-1 session containing two hypothetical candidate
eligibility explanations and a bounded evidence-request analysis. Candidate objects enter through named
premise identity projections. The full result retains dependencies, hypothetical origins, prepared child
request/result and investigation rows. No row is an observed patient, source assertion or clinical choice.

Run `trialledger reason --request evidence-investigation-request.json` from this folder, saving its output
separately. The committed result belongs to its writing version. The focused `design_session` discovery
view also contains a runnable baseline and full revision; `evidence_requests` explains variables and limits.
The separate real-source diabetes walkthrough shows full managed revision without adopting historical
restrictions into a new draft automatically.
